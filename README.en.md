# Vibe Coding Toolkit | Gabriel Edition

![Illustrated workbench: planning, building and checking](imagens/capa.png)

**From an idea to working software, with AI and clear decisions.**

I'm Gabriel. I develop websites and applications and am completing my Data Science degree at Mackenzie. I prepared this guide with Codex assistance to organize what matters when I work with AI: explain the problem, choose the tools, build in small steps and check the result.

## One idea, a few steps

![Illustration of separate planning, building and review tasks](imagens/agentes.png)

Understand → decide → build → test → record.

Not every task needs multiple agents. A small change may fit in one conversation. Delegation helps when each part has a clear goal and someone checks the combined result.

## What's included

Seven guides in each language, fifteen adaptable requests per language, documentation templates and two AI-generated illustrations created for this edition. This is a usage and adaptation guide, not an installer or a complete translation of every file in the original toolkit.

Templates help prepare a project. Installation, compatibility and actual behavior still need to be checked in the user's environment.
