Os links internos, os arquivos de imagem, a correspondência de arquivos entre idiomas e os caminhos das referências na revisão original são conferidos antes do empacotamento. Essa conferência valida a organização documental, não a execução das ferramentas citadas.

## Limites

Esta edição não instala programas, não executa os prompts, não testa integrações externas e não distribui aplicativos de outros projetos. Os exercícios são propostas para o leitor. As instruções detalhadas de instalação continuam nas referências originais; confira suas versões atuais antes de executar.

O pacote contém apenas documentos e ilustrações. A publicação no GitHub é uma etapa separada.
