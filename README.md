## Uma ideia, algumas etapas

![Ilustração de tarefas separadas de planejamento, construção e revisão](imagens/agentes.png)

Entender → decidir → construir → testar → registrar.

Nem todo trabalho precisa de vários agentes. Uma alteração pequena pode ser resolvida em uma única conversa. Dividir ajuda quando as partes têm objetivos claros e alguém confere o conjunto.

## O que você encontra aqui

Sete guias em cada idioma, quinze pedidos adaptáveis por idioma, modelos de documentação e duas ilustrações criadas com IA para esta edição. É um guia de uso e adaptação, não um instalador nem uma tradução integral de todos os arquivos do toolkit original.

Os modelos ajudam a preparar um projeto. Instalação, compatibilidade e funcionamento precisam ser conferidos no ambiente de quem usa.
